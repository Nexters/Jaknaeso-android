# 루피 Loopy
나를 알아가는 가치관 유형 검사하기

## 구글 플레이 스토어
[구글 플레이 스토어 링크](https://play.google.com/store/apps/details?id=com.jaknaeso.app&hl=ko)

## ✅ 주요 기능
Loopy는 질문을 받고, 선택을 하며, 회고를 작성하며 본인의 가치관을 탐색해나가는 앱입니다. 
15일 동안 질문을 받고, 이 질문들을 마무리하면 본인의 선택에 따라 가치관 캐릭터를 부여받고 본인의 가치관을 탐색할 수 있는 기회를 얻습니다. 
가치관 캐릭터는 swartz의 보편적 가치 이론을 바탕으로 만들어졌으며, 각 성향에 따라 주요 특성, 강점, 약점 등을 확인해 볼 수 있습니다.


### 화면 구성
1. 온보딩 화면 <br>
2. 온보딩 결과 확인 <br>
3. 15일 간의 질문 및 회고 작성 <br>
4. 회차별 캐릭터 및 회고 확인 <br>
